Section 2: Architecture & The 6 OOP Pillars Walkthrough 00:40 – 01:30 (50 sec)
🖥 Visual Action (What to show on screen) In Visual Studio, open and scroll through Models.h, highlighting the classes Person, Customer, and Employee. Briefly switch tab to DatabaseService.h.
🎤 Exact Dubbing Speech (Read aloud clearly) "Before running the live system, let us examine how our codebase demonstrates all six fundamental OOP pillars.

First, Classes and Objects: We modeled real-world entities into modular classes such as Person, Customer, and Employee, which are dynamically instantiated during execution.

Second, Encapsulation: Private attributes like names, contact numbers, and passwords are fully protected and accessible only via controlled public properties.

Third, Abstraction: Our base class Person is an abstract class with a pure virtual method, GetRoleDescription(), while our DatabaseService abstracts away MySQL query connections from the user interface.

Fourth, Inheritance: Both Customer and Employee inherit directly from our abstract Person base class to share core attributes without code duplication.

Finally, Polymorphism: Both derived classes provide distinct overrides for GetRoleDescription() and GetSummary(), resolved dynamically at runtime."
